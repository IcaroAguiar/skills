# Composition Models

Choose a governing spatial relationship, not a template.

- **Timeline-led** — order and time determine state and next action.
- **Object-led** — a product, person, document, or artifact anchors identity.
- **List-detail continuity** — selection and inspection form one continuous task.
- **Balance-led** — a primary value and its movements govern the experience.
- **Map-led** — location determines nearby content and action.
- **Content-first reader** — comprehension, progress, and decision are linked.
- **Conversational** — dialogue and composer govern progress.
- **Command center** — signals, exceptions, and interventions share one field.
- **Progressive task canvas** — visible work evolves toward completion.
- **Spatial workspace** — tools and artifacts maintain stable spatial roles.
- **Immersive media** — media is the surface; chrome recedes.
- **Profile-led identity** — a person or entity organizes related actions.
- **Collection-led discovery** — browsing and comparison govern attention.
- **Evidence-to-decision** — observations accumulate into a judgment.

Declare:

```text
Dominant composition:
Primary object or axis:
Focal region:
Secondary regions:
Entry:
First recognition:
Current state:
Dominant decision:
Secondary escape:
Return path:
Selection → state → action relationship:
```

Reject a model chosen because it is fashionable or because its components are
easy to source.

## Collections have more than one shape

A collection of records is not automatically a table. Choose by the work done
with the records:

| Work | Composition | Typical form |
| --- | --- | --- |
| Decide one case at a time | Evidence-to-decision, object-led | A queue of identity cards with the next case in focus; a dossier with a checklist beside the decision |
| Move items through stages | Timeline-led or progressive task canvas | A pipeline of numbered stages with item cards, plus a lane for items that left the flow |
| Understand a structure | Map-led or spatial workspace | An org chart or tree with counts per node and a side panel on selection |
| Plan work in time | Timeline-led | A calendar band with "today", each item drawing its own domain cycle |
| Compare many similar records | Collection-led discovery, list-detail continuity | A framed table with few columns and on-demand detail |
| Watch exceptions | Command center | Signals grouped by consequence, with the intervention next to each |

Use the table when comparison across rows is the task. When the honest answer
is another row of this table, the framed table is the generic fallback, and the
screen needs its own form.
