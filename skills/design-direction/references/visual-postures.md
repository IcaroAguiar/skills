# Visual Postures

A posture is a decision system, not an adjective.

| Posture | Observable consequences |
|---|---|
| Clinical calm | stable rhythm, warm-neutral base, clear state restraint, humane imagery, low-distraction motion |
| Technical precision | compact measure, explicit alignment, exact data hierarchy, crisp geometry, deterministic feedback |
| Editorial clarity | strong type roles, controlled measure, narrative sequence, selective imagery, spacious transitions |
| Premium restraint | few high-quality materials, controlled contrast, precise proportions, quiet motion, no effect stacking |
| Consumer confidence | recognizable objects, reassuring progress, decisive action, legible value hierarchy, positive feedback |
| Playful utility | expressive selection, friendly form, responsive motion, bounded novelty, conventional completion paths |
| Operational density | scan-first rows, stable action geography, compressed rhythm, strong change detection, minimal ceremony |
| Quiet authority | sober scale, limited accent, deliberate whitespace, strong language, rare elevation |
| Crafted simplicity | few elements with highly controlled proportions, type, states, and transitions |
| Expressive lifestyle | imagery-led identity, bold composition, atmospheric color, richer transitions, strict usability guardrails |

For the selected posture specify its effect on composition, type, density,
color, form, material, iconography, imagery, movement, feedback, and allowed
expression. If the posture does not change those decisions, it is only a label.
