# Hierarchy and Layout Grammar

Create identity and organization without decorative packaging.

## PageHeader identity

Distinguish:

- **Page:** destination or primary task.
- **Entity:** focused object and essential attributes.
- **Section:** subject within the page.
- **Component:** local functional unit.
- **Context label:** orientation that stays subordinate to the title.

Build the PageHeader with typography first. Add only auxiliaries that answer where the user is, what the object is, or what they can do:

- breadcrumb or hierarchical return;
- type family, optical variant, or display style consistent with identity;
- concise description;
- avatar, icon, or entity mark when it improves recognition;
- global state or essential metadata;
- page-level action;
- local navigation that changes the content below.

### Mode-scaled expression

- **Operational:** compact title, nearby context and action, preserved work area.
- **Analytical:** question-led title with period, unit, and global controls.
- **Transactional:** step or outcome title; progress only for a real sequence.
- **Editorial/informational:** stronger voice, reading measure, authorship, and idea progression.
- **Persuasive:** headline, proof, and CTA may lead a narrative sequence.

An expressive title need not be large. Use size, weight, width, tracking, leading, contrast, and typographic voice in proportion to the surface mode.

### PageHeader criterion

The header passes when:

1. it remains identifiable without background, border, radius, or shadow;
2. it clearly outranks section headings;
3. every auxiliary orients, identifies, or enables action;
4. action, state, and local navigation remain tied to the title;
5. wrapping, zoom, and mobile preserve title, context, and essential action;
6. it does not default to the eyebrow + oversized title + generic description + floating CTA constellation.

## Layout grammar

Choose the mechanism that expresses the relationship:

| Relationship | Suitable mechanisms |
|---|---|
| Same group | proximity, alignment, repeated rhythm |
| Subject change | space, section heading, divider |
| Plane change | tonal band, continuous panel |
| Alternatives in one context | tabs, content switcher |
| Optional content | disclosure, accordion |
| Extensive hierarchy | local navigation, index |
| Collection and detail | split view, master–detail |
| Metadata | structured list, definition list |
| Real sequence | progress, timeline, steps |
| Comparison | aligned grid, list, table |

Use:

```text
primary grammar: grid, alignment, space
secondary grammar: typography, dividers, lists
exceptional grammar: tonal plane, containment, functional elevation
```

### Layout criterion

The page passes when:

1. regions remain identifiable without outlining each one;
2. equal mechanisms express equal relationships;
3. variation changes hierarchy or use mode;
4. no mechanism exists merely to add variety;
5. rhythm is recognizable without becoming mechanical;
6. mobile recomposes the grammar instead of stacking desktop containers.

Whitespace and dividers alone can produce monotony and weak hierarchy. Decorative variety can produce another container soup. Tonal bands and narrative scale belong naturally to editorial or persuasive surfaces; use them in operational workspaces only for a real plane, state, or task change.
