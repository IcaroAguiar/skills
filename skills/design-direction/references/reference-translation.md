# Reference Translation

Extract before translating:

- function;
- proportion;
- rhythm;
- hierarchy;
- material;
- behavior;
- asset role;
- context dependency.

Translate into the destination domain:

| Source observation | Functional reading | Contextual translation |
|---|---|---|
| dominant financial card | focal object, identity, selection | focal encounter, patient, plan, or evidence object |
| large balance | priority value | next decision, time, progress, or clinical status |
| portrait | identity and trust | person, patient, author, or responsible party |
| carousel | small peer-object selection | use only when peer objects and visual browsing matter |
| bottom navigation | top-level destinations | adapt destinations and platform conventions |

Do not transplant the source object literally when the destination task differs.
