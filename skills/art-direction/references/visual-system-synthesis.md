# Visual System Synthesis

Define roles and application, not a palette or token list.

## Typography

Define navigation title, task title, focal value or object, section title,
body, instruction, metadata, state, action, and caption. For each state
importance, contrast, measure, rhythm, wrapping, localization, and enlarged-text
behavior.

## Color

Define base, grouped, focal, selection, action, positive, warning, error,
primary content, and secondary content roles. State where each appears and
which roles must never compete.

## Form

Define radius logic, dominant geometry, stroke use, icon language, image
treatment, proportions, and relationship between compact and expressive
components. Repeated rounded rectangles are not a system.

## Surfaces and depth

Define:

- base plane;
- grouped plane;
- focal surface;
- selected surface;
- persistent material;
- overlay or sheet;
- manipulated object.

For each, state function, duration, hierarchy, behavior, and when not to use.
Never reduce materiality to card versus no card.

## Density and rhythm

Map tight, normal, and separating intervals to semantic relationships. Use
proximity for relation and larger pauses for context change. Do not apply one
gap or padding value everywhere.

## Output check

The rendered hierarchy should remain legible after removing decorative effects.
Every remaining effect must communicate material, state, spatial relation, or
brand meaning.
