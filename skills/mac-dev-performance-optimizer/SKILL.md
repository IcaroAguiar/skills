# Mac Dev Performance Optimizer

## Overview

Use a measure-first cleanup loop for macOS dev machines. Preserve user data, local Postgres, Docker volumes, browser profiles, cookies, history, sessions, editor state, and active repos by default.

## Rules

- Start with `report`; do not cut blindly.
- Treat `~/Library/Application Support`, browser profiles, databases, Docker volumes, and Postgres data as protected.
- Prefer regenerable targets: caches, update packages, crash logs, old build artifacts, Chrome on-device models, dead worktrees, and selected `node_modules`.
- Do not run Codex log/session maintenance while Codex is open.
- Keep monitoring apps open if requested, but record their RSS as a tradeoff.

## Quick Commands

```bash
SKILL_DIR="/Users/icaroaguiar/.agents/skills/mac-dev-performance-optimizer"
"$SKILL_DIR/scripts/mac_dev_optimizer.sh" report
"$SKILL_DIR/scripts/mac_dev_optimizer.sh" apply-safe --yes
"$SKILL_DIR/scripts/mac_dev_optimizer.sh" apply-safe --yes --close-chrome --restart-monitors
"$SKILL_DIR/scripts/mac_dev_optimizer.sh" docker-prune --yes
"$SKILL_DIR/scripts/mac_dev_optimizer.sh" codex-final-cut
```

## What `apply-safe` Does

- Applies reversible Chrome policies:
  - block local GenAI foundation model download;
  - enable Memory Saver/High Efficiency;
  - disable Chrome background mode.
- Removes regenerable Chrome model/cache directories only when Chrome is closed or `--close-chrome` is passed.
- Removes regenerable app caches and update leftovers for GoogleUpdater, Spotify, Discord, Apple text understanding, Apple Python cache, GeoServices, and Google cache.
- Restarts Stats if it is stuck under an updater/DMG wrapper.
- Runs `pnpm store prune`.
- Reports `uv tools`, `pnpm store`, `Codex`, `Chrome`, Docker, launch agents, large `node_modules`, and dev roots.

## Optional Cuts

- `docker-prune --yes`: prunes Docker images/build cache/containers but never volumes.
- `remove-dormant-node-modules --yes`: removes only the conservative known dormant list, and only if the repo is clean.
- `archive-tetra-launchagents --yes`: moves `local.tetra.*.plist` out of LaunchAgents.
- `codex-final-cut`: runs the Codex maintenance script only if Codex is closed.

## Reversal Notes

Chrome policies are local defaults and can be removed:

```bash
defaults delete com.google.Chrome GenAILocalFoundationalModelSettings
defaults delete com.google.Chrome HighEfficiencyModeEnabled
defaults delete com.google.Chrome MemorySaverModeSavings
defaults delete com.google.Chrome BackgroundModeEnabled
```

Removed caches and `node_modules` are regenerated by apps/package managers. Removed Docker images/build cache rebuild on demand. Docker volumes are never removed by this skill.
