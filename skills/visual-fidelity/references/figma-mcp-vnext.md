# Figma MCP vNext

When Figma exists, use this source priority:

1. Figma MCP design context.
2. Code Connect.
3. Figma variables/tokens.
4. Approved screenshot of the frame.
5. Screenshot-only fallback, only with justification.

Requirements:

- record Figma file, node, frame, and approval marker;
- extract variables/tokens when available;
- preserve real components when Code Connect exists;
- use design metadata before screenshot estimation;
- do not degrade to screenshot-only without documenting why.

Screenshot from Figma is validation evidence, not a replacement for structured design context.
