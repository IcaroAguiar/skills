# Screenshot-Only vNext

Screenshot-only sources require exhaustive analysis before implementation.

Required:

- reference manifest;
- atlas;
- browser/presentation frame classification;
- section decomposition;
- typography inventory;
- image/crop inventory;
- decorative/texture/shadow inventory;
- proportions, spacing, CTAs, and overlays;
- visual checklist;
- ambiguity confidence.

Block implementation when the analysis is shallow.

Do not accept generic phrases:

- "layout moderno"
- "cards parecidos"
- "cores similares"
- "hero com imagem"
- "botao destacado"

Every relevant visible detail appears as landmark, token, section, crop, checklist item, allowed deviation, or documented ambiguity.
