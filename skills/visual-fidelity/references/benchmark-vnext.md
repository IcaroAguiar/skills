# Benchmark vNext

The skill must include a minimum hardening benchmark.

Cases:

1. Self-reference defense: screenshot from current route as golden fails.
2. Missing provenance: absent manifest blocks.
3. Incomplete IR: visible detail not represented blocks.
4. Critical landmark missing: closeout fails even if diff is acceptable.
5. Cheap executor packet: packet without `targetFiles` or `doneWhen` is invalid.
6. Baseline update fraud: golden updated in same run blocks.
7. Regional rubric: high global score with critical region failure blocks.
8. Multi-turn preservation: previous required landmarks remain mandatory after later packets.

Benchmark pass means protocol compliance, not final visual beauty.
